# RB Charity Foundation

Modernized MERN portfolio rebuild of the RB Charity Foundation website.

## Stack

- React 19
- Vite 8
- Tailwind CSS 4
- Node.js
- Express 5
- MongoDB + Mongoose 9

The project preserves the original MERN/Vite/Tailwind architecture while upgrading the implementation to the current stable versions of the stack.

## Local setup

Requirements:

- Node.js 22.12 or newer
- npm
- MongoDB locally or a MongoDB Atlas connection string

```bash
npm install
cp .env.example .env
npm run dev
```

On Windows PowerShell, create `.env` with:

```powershell
Copy-Item .env.example .env
```

Development servers:

- Frontend: `http://localhost:5173`
- API: `http://localhost:5000`

## Environment

Set `MONGODB_URI` in `.env` before using database-backed features.

## Foundation direction

RB Charity Foundation is positioned as the social-impact arm of the RB group: part of the profits generated by group businesses can support charitable initiatives, while the public can also contribute through donations, volunteering and partnerships.

No legal registrations, impact figures, campaign totals, beneficiary counts or payment credentials should be published until verified.
